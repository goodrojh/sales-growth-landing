# Лендинг «Вектор продаж» — подбор, обучение и KPI для отделов продаж

Next.js (App Router) + Tailwind CSS v4 + framer-motion + lucide-react. Статический экспорт, публикация на GitHub Pages командой `npm run deploy` (ветка `gh-pages`).

## Запуск
```bash
npm install
npm run dev
```

## Что заменить перед запуском
- `lib/config.ts` — название бренда, телефон, e-mail, мессенджеры, часы работы.
- `NEXT_PUBLIC_FORM_ENDPOINT` — URL для приёма заявок (Formspree, Telegram-бот, webhook CRM). Без него формы показывают экран успеха, но заявки никуда не уходят.
